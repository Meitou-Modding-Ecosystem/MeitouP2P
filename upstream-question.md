# Remote character presentation in MeitouClient

The first flat-world test proved the host could grant a character and resolve a guest's order. The guest initially observed the result as coordinates. We asked which interface should present the host-owned character on the guest. Martin confirmed that no remote-character-state hook existed at the time. [Issue and maintainer's reply](https://github.com/VlcekM/MeitouClient/issues/749#issuecomment-6898903424)

The Stoat fixture subsequently demonstrated guest picking and movement in two visible stock 0.20.0 clients. Co-op owns the private snapshot and input hooks. Other modes can use the connector independently. [Stoat results and replay](https://github.com/Meitou-Modding-Ecosystem/MeitouP2P-Coop/blob/main/docs/stoat-results.md)
